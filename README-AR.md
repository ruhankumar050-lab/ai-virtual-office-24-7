# 🏢 المكتب الافتراضي الذكي 24/7 (مجاني بالكامل)

نظام مكتب افتراضي متكامل يعمل ذاتياً 24 ساعة بدون تدخل بشري (مثل فكرة Claude Virtual Office / Agent Teams) مع واجهة عربية تفاعلية حية.

## 👥 فريق العمل داخل المكتب
1. **المدير التنفيذي (CEO):** يبتكر المشاريع الجديدة تلقائياً، يوزع المهام على الأقسام، ويعتمد المخرجات النهائية.
2. **مديرة الموارد البشرية (HR):** تراقب ضغط العمل، وتقوم بتوظيف موظفين متخصصين جدد تلقائياً عند الحاجة.
3. **مطور التطبيقات (App Dev):** يبني تطبيقات ويب كاملة ومستقلة (`HTML/CSS/JS`) جاهزة للتشغيل الفوري.
4. **مراجعة ومعدّلة الكود (QA & Auto-Fixer):** تفحص التطبيقات تلقائياً وتصلح الأخطاء وتحسّن التصميم (`v1` ← `v2`) **بدون الرجوع إليك**.
5. **صانع الفيديوهات (Video Creator):** يكتب السيناريو ويصمم مشاهد الفيديو والتعليق الصوتي.
6. **مونتيرة الفيديو (Montage Editor):** تضيف الانتقالات، تصحيح الألوان، والترجمة المتزامنة مع إمكانية تصدير الفيديو بصيغة `.webm`.

## ⚡ التشغيل الفوري الآن
```bash
cd ai-virtual-office
node server.js
```
ثم افتح المتصفح على: `http://localhost:3000`

## ☁️ كيف تشغّله 24 ساعة مجاناً للأبد؟

### الخطوة 1: اختيار ذكاء اصطناعي مجاني (0 دولار)
من تبويب **⚙️ التشغيل المجاني 24/7** داخل المكتب اختر أياً من:
- **المحرك الذكي المدمج:** يعمل فوراً بدون أي API Key.
- **Google Gemini Free Tier:** احصل على مفتاح مجاني من Google AI Studio (`gemini-2.5-flash`).
- **Groq Free Tier:** مفتاح مجاني وسريع جداً (`llama-3.3-70b-versatile`).
- **OpenRouter `:free`:** نماذج مجانية مفتوحة المصدر.
- **Ollama:** لتشغيل النماذج مجاناً وبلا حدود على جهازك أو سيرفرك الخاص.

### الخطوة 2: استضافة مجانية 24/7
- **الخيار الأفضل (Oracle Cloud Always Free):** استأجر سيرفر Ubuntu مجاني للأبد (ARM/AMD Always Free)، انسخ المجلد وشغّله عبر `docker compose up -d` أو `pm2 start server.js`.
- **الخيار السريع (Render / Koyeb Free Tier):** ارفع المجلد على GitHub واربطه مجاناً، واستخدم موقع **UptimeRobot** المجاني لعمل Ping كل 5 دقائق على مسار `/health` لإبقاء المكتب مستيقظاً 24 ساعة.
- **على جهازك الشخصي:** شغّل `docker compose up -d` وسيعمل المكتب في الخلفية تلقائياً حتى بعد إعادة تشغيل الجهاز.
